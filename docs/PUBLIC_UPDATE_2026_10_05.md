# 2026-10-05 공개 업데이트 범위

비교 기준은 2026-10-01 공개 main `46f65ba`(v2.2.0)다. 이번 공개는 **기존 엔진 코드와 사용 안내**이며 작업대 화면 데모는 포함하지 않는다.

일부 운영 재무 경로와 실제 위험 총액은 미지원·입력 미확인 상태가 남아 있다. 합성 엔진 검증을 운영 복구·실계좌 계산 성공으로 표현하지 않는다. 진행 중인 공통 재무 변경은 이번 공개에 포함하지 않았다.

새 계산은 별도 `invest_agent.scenarios` 패키지로 추가한다. 기존 `trading.scenarios`와 호출 경로를 교체하지 않는다. 기존 후보·섹터·관찰 데모는 보존한다. 운영 저장소의 Git 이력은 가져오지 않고 선별된 코드·합성 입력만 가공했다.

공개 사용 안내는 비공개 작업대에서 실제로 연결한 전체 흐름을 설명한다. 공개 저장소를 설치하면 모든 화면·LLM 분석·MCP·예약이 제공된다는 뜻은 아니다. [실행할 수 있는 새 범위](PORTFOLIO_SCENARIOS.md)와 [작업대 사용 흐름](WORKBENCH_WORKFLOW.md)을 구분했다.
