- 원본 엔진을 대조하여 실제 최신 변경을 이식했습니다. 기존 공개판의 키 기반 계좌 별명, 차트 렌더러 주입과 공개 전용 모듈을 보존했습니다.
- 차트·분석·재무·감시·사이클·연구 계산은 기존 구현을 사용합니다. 공개 데모는 별도 생성기와 명시적 history/financial 어댑터를 주입합니다.
- 개인 환경설정·브로커 인증 자동 탐색·운영 프로세스 자동 시작은 제거했습니다. 계좌 입력은 호출자가 명시한 정규화 파일 또는 합성 자료만 사용합니다.

- 공식 자료 파서와 선택적 DART/SEC 수집 코드는 남겼습니다. 환경 변수는 이용자가 직접 설정하며 개인 설정 파일을 읽지 않습니다. 합성 기본 경로에서는 수집하지 않습니다.
- 자동 Codex 초안은 명시적 환경 변수 opt-in 전에는 실패합니다. 데모 시작과 보통 화면 조회는 Codex를 실행하지 않습니다.

- 원본의 운영 설정에 의존하던 제외 종목 테스트는 명시적인 합성 정책 주입으로 바꿨습니다. 보고서 응답에 추가된 문서 링크를 저장 원문과 구분하도록 기존 테스트를 갱신했습니다. 역할 토큰 없는 MCP의 하위 호환 권한 승격은 허용하지 않습니다.

## 구조의 한계

현재 최신 UI 코드는 `workbench/` 소스 checkout으로 제공합니다. 기존 `pip install .`로 만드는 엔진 wheel에 UI를 포함했다고 주장하지 않습니다. 루트 런처와 requirements 파일로 실행하세요. 서버는 로컬 단일 사용자 용도입니다. 인터넷 공개 서버, 다중 사용자 권한, 실제 주문 실행은 제공 범위가 아닙니다.

라이선스 고지를 보존한 두 vendor 라이브러리 외에 개인 자료를 자산으로 넣지 않았습니다. 패턴 검사는 임의 문장 속 모든 개인정보나 저작권 적합성을 보증하지 않으므로, 기존 `PUBLICATION.md`의 별도 검수 후 정확한 트리를 공개해야 합니다.
