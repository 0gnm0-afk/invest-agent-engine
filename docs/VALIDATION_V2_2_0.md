# v2.2.0 검증 기록 — 2026-10-01

이 기록은 공개 후보의 동작 검증이며 독립 공개정보 검수·게시 완료를 뜻하지 않는다. 개인 시장 수집 작업의 성공 여부를 이 결과에 포함하지 않았다.

## 실행 환경과 결과

Windows, Python 3.12.14의 새 가상환경에 `pyproject.toml` 의존성을 설치했다. 기존 운영 환경은 사용하지 않았다. 설치 후 테스트·데모 Python 프로세스와 자식 프로세스에 네트워크 연결/DNS 차단을 적용했다. 설치 자체는 패키지 다운로드를 사용했다.

| 확인 대상 | 실행 | 관찰 결과 |
|---|---|---|
| 의존성 정합성 | `python -m pip check` | 충돌 없음 |
| 전체 공개 회귀 | `python -B -m unittest discover -s tests -v` | 332개 통과, 실패·skip 없음 |
| 신규 계산/데모 | entry 11 + watch 8 + base 9 + demo 3 | 31개; 위 전체 검사에 포함 |
| 관찰·진입 합성 데모 | `examples/watch_review_demo.py` | 7사례, 진입 조건 충족 1개; JSON·HTML 생성 |
| 기존 합성 시장 데모 | `examples/market_review_demo.py` | 유효 입력 8, 의도적 품질 제외 2, 후보 8, 차트 4/4 |
| 기존 합성 계좌 데모 | `examples/demo.py` | exit 0; 일부 입력 결측을 partial로 유지 |

기존 301개에 신규 31개를 더한 검사 수다. 비공개 통합 검사나 실제 수집 수치를 포함하지 않는다. 표준 데모 명령의 입력은 공개 저장소의 합성 생성기/fixture뿐이다. 생성 보고서·차트·DB·로그는 저장소 밖에 두며 공개 파일에 포함하지 않는다.

초기 의존성 없는 기본 Python으로 시도한 좁은 검사는 `fastmcp` import 실패였다. 선언된 의존성을 새 가상환경에 설치한 뒤 위 전체 검사가 통과했다. 이 설치 전 실패를 코드 회귀 통과로 세지 않았다.

## 확인한 경계

- 완료/미래 봉, 평가봉에 의한 과거 피벗 오염, 약한 거래량·윗꼬리, 오래된 돌파·하단 이탈·추격을 합성 반례로 검사했다.
- 바닥과 눌림의 독립 관찰, 지속 하락·급락 복귀 거부, watch/ready/entry와 결측 시장 상태를 확인했다.
- 기존 합성 경로의 실자료 출처 거부, 계좌 입력의 출처 불일치/오래된 자료 보존, 보호선 자동 채택 금지를 회귀 검사했다.
- 새 데모의 원입력 불변·중복 사례 거부·기존 출력 폴더 보호·저장소 내부 출력 금지를 확인했다.

공개정보 검사는 manifest 목록·해시, 민감 패턴, 전체 기존 공개 이력, LFS/submodule/ignored/build 범위와 독립 검수로 나눈다. 실행 로그와 고정 트리 증거는 비공개로 보관한다. 공개 검사기는 [PUBLICATION.md](../PUBLICATION.md)의 한계를 갖는다. 검수된 트리와 달라지면 재검수한다.

## 실행하지 않은 항목

공개 코드는 검토 보조 계산이며 금융 의사결정의 정확성이나 운영 서비스의 가용성을 인증하는 결과가 아니다.
