# Trend, consolidation and breakout observation

The screen evaluates explicit rules against completed synthetic or user-supplied daily candles. Trend alignment, relative strength, consolidation shape, volume and confirmed breakout timing remain separate evidence. A watch candidate is not a trade recommendation. No lecture, book or report source text is distributed.

Implementation and exact defaults: `src/invest_agent/trading/momentum_entry.py`, `momentum_watch.py`, `workbench/scripts/watch_review.py`, `downtrend_approach.py`. Historical calculations do not certify future returns.
