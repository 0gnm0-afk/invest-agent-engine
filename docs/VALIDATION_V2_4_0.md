# v2.4.0 MCP 공개 검증

이번 변경은 내부 MCP 도구 16개·로컬 통신 코드·협업 계약 공개와 README 갱신이다. 기존 계산 코드는 변경하지 않았다.

| 확인 범위 | 결과 |
|---|---|
| STDIO 초기화·도구 열거·합성 입력 조회→저장→재조회 | PASS, 메모리 합성 예제 |
| 명시 루트 필수·외부 주소 거부 | PASS, 실제 계좌/수집 접근 없음 |
| 로컬 HTTP 연결·역할 자격 전달·일반 토큰 대체 차단 | PASS, 임시 로컬 모의 백엔드 |
| 서버 오류 본문의 개인 내용 미전달 | PASS, 합성 오류로 확인 |
| 합성 모드의 실제 작업대 접근 차단 | PASS |

명령: `python -B -m unittest discover -s tests -p test_workbench_mcp.py -v`. 선택 의존성 mcp 1.29.0을 설치한 환경에서 5개 검사 통과. 선택 의존성 없이는 STDIO 검사가 skip이므로 같은 결과로 간주하지 않는다. Windows 로그 문자 인코딩을 UTF-8로 지정한 뒤 다시 통과했다.

전체 작업대, 실제 계좌 위험 계산, 외부 자료 갱신, 다른 MCP 클라이언트별 설치는 이번 검사 범위가 아니다. 합성 백엔드는 네 개 작업만 시연하고 나머지는 미지원으로 응답한다. 기존 v2.3.0 계산 검증은 [이전 기록](VALIDATION_V2_3_0.md)에 보존한다.

게시 파일은 공개 매니페스트에 고정한다. 실제 DB·개인 기록·인증정보·로컬 설정·비공개 Git 이력은 제외하며, 별도의 개인정보 중심 독립 검수와 커밋 이력 검사를 거친 동일 후보만 게시한다. 게시 후 기존 public-privacy-check 결과와 원격 커밋·트리를 확인한다. 문제가 확인되면 해당 공개 커밋의 후속 되돌리기로 코드 변경을 복구하되, 이미 노출된 비밀을 되돌리기만으로 회수할 수 있다고 간주하지 않는다.
