# 합성 시장 검토 실행 (v2.1.0)

기존 공개 스크리너에 섹터 관찰, 후보별 맥락, 우선 검토 순서와 차트를 연결한 중간 릴리스다.
비공개 워크벤치의 계산·검토 기능을 공개용으로 가공했으며 입력은 코드로 생성한 합성 자료다.
로그인·계좌·API 키·네트워크가 필요 없다. 실제 시장 수집기를 재현하지 않는다.

## 실행

Python 3.12 이상, 저장소 루트에서 기존 설치 방법(`python -m pip install -e .`)을 따른다.

```sh
python examples/market_review_demo.py --output ../synthetic-market-review
```

기본 우선 검토는 시장별 2개다. `--limit-per-market 3`으로 바꿀 수 있으며 0이면 차트만 생략한다.
출력은 패키지 밖의 새 폴더여야 한다. 기존 폴더는 덮어쓰지 않는다. 생성된 `report.html`을 연다.
출력 `state: partial`은 의도적으로 잘못된 최신 봉 2개를 제외했기 때문이다. 정상 데모는
전체 입력 10개, 유효 8개, 후보 8개, 섹터 4개, 우선 검토·차트 4개다.
정상 partial은 종료 코드 0, 차트 실패는 1, 잘못된 출력 경로·설정은 2다.

| 결과 | 내용 |
|---|---|
| synthetic-input.json | 가상 KR/US 종목·OHLCV·분류·벤치마크·세션 |
| screen.json | 기존 Universe → S1–S4 → 이동평균 위치 판정과 원순서 |
| sectors.json | 지표별 사용·제외 종목, 결측 사유, 섹터 계산 |
| context.json | 후보를 유지한 섹터 맥락과 별도 연구 순서 |
| priority.json | 선택·미선택을 포함한 전체 후보의 비교 축과 이유 |
| quality.json / charts.json | 자료 제외와 차트 생성 상태를 각각 보존 |
| report.html / charts/ | 요약 및 우선 검토 종목의 HTML·PNG·차트 근거 JSON |
| artifact-hashes.json | 생성 파일의 SHA-256 (이 파일 자체 제외) |

## 계산과 공개용 변경

- 종목 판정은 기존 공개 엔진을 재사용한다. 새 runner는 OHLCV·세션·완료 여부를 먼저 검증해
  잘못된 시계열 전체를 제외하고 `unavailable` 행으로 보존한다. 결측 구간을 메우지 않는다.
- 섹터 63/126세션 수익률은 해당 기간에 자료가 모두 있는 고정 구성 종목의 일별 수익률을
  동일비중으로 평균해 복리 연결한다. 시작·끝 수익률의 단순 평균이 아니다.
  RS는 `(1 + 섹터 수익률) / (1 + 합성 벤치마크 수익률) - 1`이다.
- 절대 추세는 126세션 곡선의 SMA20/60 대비 위치와 SMA20의 5세션 변화다.
  참여 폭은 SMA60 위 종목 비율이다. 거래활동은 당일 거래량 / 직전 20세션 평균이며
  당일은 분모에서 제외한다. 거래활동은 자금 순유입이나 방향 지표가 아니다.
- 기간·지표별 사용·제외 수와 사유를 남기고 5종목 미만 표본을 표시한다. 벤치마크나 분류가
  없으면 RS·섹터 맥락은 결측이다. 분류 누락을 후보 탈락으로 바꾸지 않는다.
- 우선 검토는 최근 단계 → 장기 SMA 근접 → 저항 접근/종가 돌파와 지지 이탈 구별 →
  섹터 RS·추세·참여 폭 → 단계 경과 → RS → 원순서의 사전식 비교다. 가중 합산 점수는 없다.
  전체 후보와 원 판정을 보존하며 검토 상한 밖인 이유도 기록한다.
- 차트는 현재 기간에서 선택한 추세선을 B 앵커 확정일부터 첫 고가/저가 침범까지 그린다.
  과거 앵커는 빈 원, 당일 확정은 한 점이다. 과거 당시 선택 가능했던 선의 백테스트가 아니다.
  장기 이동평균 표시 이력이 부족하면 차트 메타데이터에 그대로 표시한다.

공개 입력은 가상 회사명·가상 분류·380개 평일로 고정된다. 기준일은 입력 마지막 세션이며
실행 당일 시세가 아니다. 거래소 휴일·기업행동·실제 분류 이력은 재현하지 않는다.
KR·US 모두 합성 벤치마크를 사용한다. 비공개 운영의 한국 시장 전체 동일비중 비교,
실제 공급자별 조정가격·거래량 관계, 분류 출처·시효 검증, 수집 실패 재시도는 포함하지 않는다.
`synthetic` 표시는 데이터 익명화나 공개 허가 기능이 아니다. 실제 자료를 이름만 바꿔 넣어서는 안 된다.
원시 자료·계좌·인증·사용자 판단·강의 원본은 제공하지 않는다.
이 경로에는 실제 입력을 읽는 CLI도 없다. 기존 v2.0.0 계좌 데모/기능과는 별도 실행 경로다.
Evidence·Pages·Cloud·Telegram 작업은 포함하지 않는다. 결과는 투자 판단 보조 자료이며 매매 지시가 아니다.

## 검증

```sh
python -m unittest discover -s tests -p test_market_review.py -v
python -m unittest discover -s tests -v
python -B scripts/check_git_publication.py --repo .
```

검사는 합성 계산 정답, 후보/원입력 불변, 결측·오류 격리, 확인시점 이후 차트,
네트워크 차단 상태의 종단 실행, 기존 출력 보호를 확인한다. 실제 운용 성과 검증은 아니다.
공개 파일 검사와 독립 검수 절차는 [PUBLICATION.md](../PUBLICATION.md)를 따른다.
