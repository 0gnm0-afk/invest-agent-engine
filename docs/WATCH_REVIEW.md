# 관찰·진입 구분의 공개 재현 범위

v2.2.0은 `momentum_entry`, `momentum_watch`, `base_structure` 계산을 추가한다. v2.1.0의 기존 후보 선정·섹터 검토를 덮어쓰지 않는다. 비공개 운영 흐름에서 사용하던 계산을 가져오되 비공개 운영 수집기·실제 계좌·사용자 판단·자료 원문과 통합 화면은 추가하지 않았다. 기존 공개 공급자 연결은 유지하며, [연결 범위와 미검증 항목](../PUBLICATION.md#유지한-기존-공개-공급자-연결)을 별도로 명시한다.

## 변화와 확인할 증거

| 비교 기준 | 이전 공개본 | v2.2.0 | 재현 |
|---|---|---|---|
| 후보를 기다리는 단계 | 기존 S1–S4 후보/이동평균 위치·섹터·우선 검토 | 별도 watch/ready/entry 상태와 남은 조건 추가 | `test_momentum_watch.py` |
| 바닥/눌림 관찰 | 독립 base 계산 모듈 없음 | 반복 지지·범위·방향성·최근 안정화로 독립 watch 반환 | `test_base_structure.py` |
| 피벗 선택 시점 | 기존 확정 이후 차트 표시 유지 | 새 모멘텀/관찰의 기준선은 평가봉 이전 자료로 계산 | 미래봉·평가봉 극값 반례 |
| 출처/계좌 경계 | 이미 존재 | 동작 변경 없이 회귀 검증 | `test_market_review.py`, `test_account_sync.py` |

“좁은 범위에 있고 이전 저점 가까이에 있다”는 설명만으로는 지속 하락이나 급락 복귀를 제외할 수 없다. 새 테스트는 가상 경로 두 개를 만들어 `not_directional_range`와 `recent_stabilization`의 거부 근거를 확인한다. 이것은 합성 반례의 결과이며 이전 공개판에 없던 모듈의 실시장 오탐률이 얼마나 개선됐다는 측정이 아니다.

## 계산 계약

- 입력은 날짜가 증가하는 완료 OHLCV 봉이다. 미래/미완료 봉은 제외하며 비정상 값·중복/역순 날짜는 거부한다. `complete`가 없으면 완료로 취급하므로 호출자가 완료 여부를 검증해야 한다.
- 엄격 진입은 253봉 이상에서 추세, 입력 RS, 시장 상태, 사전 패턴, 거래량·종가 돌파, 유지·이격·구조 위험을 확인한다. 설정값을 계산에 적용하고 판정·거부 사유를 반환한다. `momentum_entry.analyze` 결과에는 설정 사본이 포함되지 않으므로 사용한 기본값·재정의 값은 호출자가 별도로 보관해야 한다.
- 기본 진입 RS는 80, 거래량은 이전 50봉 평균의 1.5배, 진입 나이는 2봉 이내, 최대 피벗 이격 5%/ATR 2배, 구조 하단 거리 8%다. 이 수치는 코드의 운영 가정이며 최적화된 성과 기준이 아니다.
- 관찰 RS 기본값 70, S3 관찰 60, 피벗 거리 15% 이내/ready 5% 이내다. watch/ready는 거래량·돌파·유지 등 추가 확인이 필요하다. `ready`도 시장 조건이 미충족일 수 있으며 경고가 표시된다.
- 바닥/눌림은 15·20·30·40·60·90봉 창을 검사한다. 최소 142봉에서 선행 하락/상승, 분리된 반복 지지, 범위 대비 방향성, 최근 5봉 대비 직전 5봉의 안정화 등을 확인한다. 반환 단계는 watch다.
- `structure_stop`은 차트 구조 하단 후보다. 계좌의 `current_protection_price`를 갱신하지 않는다. 범위 상단 거리÷하단 거리는 가격 기하의 비율이며 기대수익률이 아니다.
- 기존 내부 경로명 `pdf_momentum`은 결과 식별자 호환을 위해 유지했다. 강의 원문·페이지 참조·전체 방법론 재현은 제공하지 않는다. 계산 모듈은 재무·기관·질적 조건을 검증하지 않았음을 반환한다.

이 모듈만으로 종목 동일성·통화·수정주가 기준·거래소 달력·RS 모집단의 정합성을 검증하지 않는다. 호출자가 정합적인 입력을 공급해야 한다. 비공개 시장 공급자 교차검증을 이 공개판에서 실행했다는 뜻이 아니다.

## 7개 합성 사례

```sh
python examples/watch_review_demo.py --output ../synthetic-watch-review
```

| 입력 | 확인할 결과 |
|---|---|
| 돌파봉 직전의 변동성 축소 | watch/ready; 엄격 진입 아님 |
| 합성 돌파·거래량 증가·시장 지지 | entry; 정의된 조건 충족일 뿐 매수 지시 아님 |
| 같은 봉, 시장 근거 결측 | 엄격 진입 차단, 결측 상태 유지 |
| 하락 후 반복 지지 바닥 | 독립 watch, 진입 아님 |
| 상승 후 눌림 횡보 | 독립 watch, 진입 아님 |
| 완만한 지속 하락 | base 제외 |
| 급락 중 이전 저점 복귀 | base 제외 |

`synthetic_watch.py`는 수식으로 가상 OHLCV를 생성한다. 달력은 연속 날짜를 사용하며 실제 거래소 세션이 아니다. RS 95와 시장 상태도 입력 가정이다. 실제 종목명·실제 가격·수집 결과를 변형한 fixture가 아니다.

`inputs.json`에 입력, `review.json`에 전체 조건·신호·거부 사유, `report.html`에 비교표를 쓴다. 기존 출력 폴더는 덮어쓰지 않고 저장소 안에는 생성하지 않는다. 설치 후 실행에 네트워크·API 키·계좌·LLM이 필요 없다.

## 검증 한계

선별한 계산 테스트는 비공개 대시보드·수집·차트·보고서 통합 검사를 포함하지 않는다. 이전 합성 시장 데모는 별도로 유지한다. 보호선 채택·계좌 재조정·출처 불일치 거부는 기존 공개 테스트로 확인하며 새 데모가 계좌 전체를 재현한다고 소개하지 않는다.

임계값 민감도, 실시장 전수 정확도, 장기 운영, 매매 체결, 수익성, 시간 절감, LLM 모델 간 비교와 자율 조사 루프는 검증하지 않았다. 실행 환경·검사 수·관찰 결과는 [검증 기록](VALIDATION_V2_2_0.md)에 있다.
