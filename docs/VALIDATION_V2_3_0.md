# v2.3.0 검증 범위

검증일: 2026-10-05. 대상은 기존 공개 main 위에 추가한 계획·계좌 시나리오 계산과 사용 안내다. 실제 작업대 운영, 실자료 수집, 재무 공통 수정, 주문·알림은 이번 검증 대상이 아니다.

| 위험 | 확인 방법 | 관측 결과 |
|---|---|---|
| 기존 엔진 회귀 | 공개 후보에서 전체 unittest | 369개 통과 |
| 금액·수량·현금 계산 | 합성 손계산과 Decimal 결과 대조 | 기준 1,125,000 KRW / 새 계획 예제 대응 후 1,062,500 KRW 일치 |
| 조건과 체결 혼동 | 확인가격/체결가격 분리, `<`/`<=`, 완료봉·통화·가격 기준 검사 | 통과 |
| 결측을 0이나 전체 자산으로 표시 | FX·시세·불완전 계좌·현금 중복·미래 가정 결측 | 총액 null 및 보류 사유 보존 |
| 계획 버전·귀속·중복 | 고정 해시·계좌 식별자·활성 버전·물량 중복·대안 선택 검사 | 통과 |
| 입력·원기록 변경 | 계산 전후 깊은 복사 대조, 저장 RPC 모의 호출 및 재조회 | 입력 불변, 자동 채택 호출 없음 |
| 공개 CLI 외부 접근 | socket 연결 금지 상태 종단 테스트 | 새 폴더에 보고서·JSON 생성, 기존/저장소 내부 출력 거절 |
| 작도 참조 | 기울어진 채널의 날짜별 가격·고정 revision 검사 | 고정 가격으로 대체하지 않음, 변경 revision 보류 |
| 종목 간 공유 현금의 시간 순서 | 미래 매도→과거 매수 반례, 정상 이후 매수, 별도 계좌 회귀 | 독립 검수 지적 수정 후 3개 통과 |

명령:

```sh
python -B -m unittest discover -s tests -v
python examples/portfolio_scenario_demo.py --output ../synthetic-portfolio-scenario
python -B scripts/check_publication.py --root <clean-candidate>
python -B scripts/check_git_publication.py --repo <public-repository>
```

369개는 이전 332개에 계산/계획 관련 32개, 새 공개 예제 2개, 독립 검수 후 현금 시간 순서 회귀 3개를 더한 수다. 단위/종단 검사는 합성·모의 입력을 사용한다. 실제 계좌 연결·사용자 채택 권한·신뢰할 수 없는 임의 JSON 전체의 방어·LLM 판단 개선·투자 수익률을 보증하지 않는다. RPC helper의 저장 검사는 모의 함수이며 운영 DB 검증이 아니다.

공개 검사는 깨끗한 허용 파일 사본·매니페스트·독립 검수·도달 가능 이력·고정 pre-push 검사를 함께 사용한다. GitHub 검사 성공만으로 공개 전 비밀 검증을 대체하지 않는다. 실제 게시 SHA와 CI 결과는 GitHub 이력에서 확인한다.

재현 한계: 기존 설치 Python 환경으로 검사했다. 신규 PC의 전체 의존성 설치·여러 OS·실제 공급자 이용조건·실제 데이터 재배포 권한은 검증하지 않았다. 새 계산 5모듈 자체는 표준 라이브러리만 사용한다.

복구는 공개 코드의 문제가 있는 버전을 사용 중지하고 검증된 이전 버전으로 되돌리는 방식이다. 이미 공개된 정보의 회수는 코드 되돌리기로 보장할 수 없으므로 개인 자료는 공개 후보 단계에서 제외한다. 운영 DB·계좌·예약·서버는 이번 공개 작업으로 변경하지 않는다.
